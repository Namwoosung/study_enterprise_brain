# 우선 범위 통합 검토와 수정 확인

2026-11-19. 주 작성자가 U08의 고객지원·설비 구축 수업, U13 보충 수업, U16 두 수업을 본문·fixture와 대조했습니다. 독립 검토자가 남긴 U09~U12·U14~U15·S01의 수정도 통합했습니다. 보조 에이전트의 사용량 한도로 U13 보충·U16의 추가 독립 검토는 끝나지 않았으며, 아래 두 단원은 주 작성자의 교차 확인입니다. 이를 독립 검토 완료로 표시하지 않습니다.

## 설명과 계산 확인

- U08: 고객의 09:05 화면 보고와 09:20 응답 확인을 별개로 보존합니다. 고객 장비 키가 없으면 도움말의 적용을 확정하지 못합니다. 설비 예의 430 ms와 0.43 s는 같은 원천 행의 사본이므로 관측 1건입니다. 완료 시각을 10:02에서 10:10으로 정정하면 10:07 관측의 전후 분류가 달라집니다. 물질화·가상·연합 접근은 표현 모델과 배치 선택을 분리해 설명하며 실행하지 않은 엔진의 결과를 주장하지 않습니다.
- U13 보충: 어휘 점수의 조건을 표와 코드에서 대조했습니다. D02a는 A에서 8, D04a는 B에서 8이며, 두 원문 길이는 88자입니다. B에서 ‘기록’ 가중치를 제거하면 D04a와 D08a가 4점으로 동점입니다. 과거 기준일에는 D01만 유효한 매뉴얼입니다. 모의 문자열 점수를 BM25 구현이나 임베딩 성능으로 설명하지 않습니다.
- U16: Q1~Q5의 매크로 Recall@4는 Vector 0.75·Graph 0.95·Tree 0.90, MRR@4는 1·0.90·1입니다. Q6의 0개 골드는 재현율 분모에서 제외합니다. Q2 Tree의 P@2=1/2·R@2=1/4·RR=1을 별도로 계산했습니다. A3 인용만 고치면 충실성은 3/4 그대로, 인용 지표가 2/4에서 3/4로 달라집니다. 이 숫자는 가정한 순위와 사람이 구성한 답변의 산술이며 실제 시스템 우열을 측정하지 않습니다. [IR 평가 교재 §8](https://nlp.stanford.edu/IR-book/pdf/08eval.pdf), [ALCE §3.3](https://aclanthology.org/2023.emnlp-main.398.pdf#page=4)
- U12 독립 검토 수정: I-43의 ‘검사 결과 제외’ 표현을 신규 판정값 **검증 적용 대상 밖**으로 고쳤고, 검사 집계 2건에는 포함한다고 명시했습니다. 작은 fixture의 검사일·확정 발행일 동일 가정과 경계 반례를 추가했습니다. K06은 JSON 형식만 유효하고 근거 선택 지시를 어긴 모의 결과임을 명시했습니다.
- U09~U11 독립 검토 수정: 제거·설치 동사의 span, 원천 레코드와 장비 IRI의 동일성 구별, 미관찰 라벨, 암묵지 예의 설정·메모 판과 위치를 보강했습니다.
- S01 독립 검토 수정: 공개본 v1과 출판호 날짜를 구분하고 본편 연결표를 추가했습니다. 네 대표 접근의 평가 조건, 원논문의 튜플 순서 차이, 개별 장비·모델의 차이를 보강했습니다.
