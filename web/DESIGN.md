# 학습 경험 설계

목적: 프로그래밍과 기본 RAG를 아는 독자가 기업 지식의 구축·검증을 이해하고 설명하게 한다. 8개 단원을 54개의 짧은 학습 구간으로 나누고 원문 전체·근거·심화를 보존한다.

색: 종이 #f7f9fc, 본문 #20314b, 강조 #3159bf, 맥락 #e9effb, 확인 #18756b, 주의 #9c6423. 어두운 연구 도구 화면보다 낮 시간에 오래 읽는 학습 노트로 구성한다.

글자: 한국어는 시스템의 맑은 고딕/Apple SD Gothic Neo를 우선해 외부 폰트 로딩 없이 읽는다. 제목 40~52px, 본문 17px와 1.85 행간. 코드는 Consolas. 본문 폭은 약 700px로 제한한다.

배치: 왼쪽에는 학습 경로, 가운데에는 한 번에 하나의 설명, 오른쪽에는 현재 단원의 순서와 메모를 둔다. 모바일에서는 학습 경로를 접고 본문을 먼저 보여준다.

핵심 시각 요소: L02를 중심으로 작업·장비·절차·근거를 연결한 직접 선택 가능한 관계 지도. 장식용 이미지 대신 이 사례가 첫 화면에서 학습의 목적을 보여준다.

본문은 단순한 Markdown 뷰어로 끝내지 않는다. 연결 판단, 구조/시점 검증, 검토 용량, 문서 발효/수집 시점, 검색 방식별 근거 구성을 조작하는 연습을 본문에 붙인다. 학습 완료·메모·북마크는 현재 브라우저에 저장한다. 원문 문제의 해설은 접어 둔다.

검토: 숫자는 실제 순차 학습을 나타낼 때만 쓴다. 반복 카드와 큰 통계 숫자로 화면을 채우지 않는다. 관계 지도 한 곳에 시각적 강조를 두고 본문은 조용하게 유지한다. 성능을 측정한 것처럼 보이는 데모와 임의의 검색 점수는 사용하지 않는다.
