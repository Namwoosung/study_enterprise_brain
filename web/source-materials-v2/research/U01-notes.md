# U01 첫 수업 근거

2026-11-18 확인. 본 수업은 U01 일부이며 ready 상태가 아니다.

- [Second Brain 원저자 foundation](https://www.buildingasecondbrain.com/foundation): 외부 기억과 개인의 활용 목적, CODE 설명 확인. 소개 자료의 생산성 효과를 독립 실증으로 인용하지 않음.
- [WRITER Enterprise Brain](https://writer.com/blog/enterprise-brain/): 2026-09-09 제품 발표의 공유 GTM 맥락·agent 활용 설명. 일반 분야 정의나 반도체 시스템 성능 근거로 사용하지 않음.
- [Hogan et al. Knowledge Graphs v6](https://arxiv.org/html/2003.02320v6): §2 데이터 모델·질의, §3 schema/identity/context, §4 ontology 역할 구분. 본문의 E01/J17 시나리오는 교재 자체의 합성 적용이며 논문 사례가 아님.

기업 질문에서 요구를 도출한 부분과 제품 선택의 판단은 교재의 설계 설명이다. 보편적으로 검증된 단일 Enterprise Brain 아키텍처라고 주장하지 않는다. 이후 U01 확장에서는 실제 대안 흐름·개인/조직 지식 운영 비교·역할 지도를 더하고 독립 검토한다.
