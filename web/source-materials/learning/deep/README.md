# 한 단계 아래로 내려가는 심화 학습

기본 교재의 4~5일 경로를 유지하고, 필요한 내부 원리와 설계 판단을 별도 경로로 확장한다. 제목의 어려운 용어를 늘리기보다 작은 반례·계산·실행 결과를 통해 이해한다.

## 1차 반영: 의미와 연결

- [D1 의미·검증](D1_semantics.md): 조건의 방향, 존재·전체·개수, 검사 대상, 사전 추론, OWL 프로파일.
- [D2 개체 식별·자동 모델](D2_resolution.md): 후보 생성의 상한, 군집의 연쇄 오류, 속성 통합, 모델 변경 평가.

기존 사례 원천은 수정하지 않는다. 새 반례와 수치는 합성 변형으로 구분한다. 실행 범위는 [심화 검사](../examples/verify_deep.py), 조사 내역은 [심화 출처](RESEARCH.md)에 남긴다.
