# B안 로컬 통합본 확인

2026-11-19. 전체 교재·운영 배포의 완료 기록이 아니다.

- manifest의 작성된 수업만 빌드하고 각 Markdown 전체를 변환했다. 작성되지 않은 단원은 요약 카드로 만들어 넣지 않았다.
- Chromium에서 1500×1000·390×844로 모든 작성 수업의 본문과 가로 넘침, 수업 목록을 확인했다.
- RDF 사건 drive3 선택 시 SVG 값과 요약 값이 모두 9km로 바뀌는 것을 확인했다. U06의 타입 누락 선택이 RDFS 전후 결과를 보여주는지도 확인했다.
- 모바일에서는 RDF/U06/RAG 예제가 관련 설명 뒤의 본문 안으로 옮겨지는지 확인했다. 그 외 수업은 목차를 제공한다.
- rdf-1500.png, rag-390.png를 직접 열어 데스크톱의 나란한 구조와 모바일의 순서 배치를 확인했다. 이미지 보관 위치는 qa/이며 git에서는 제외한다.
- 검사 중 동일 data-value를 가진 SVG와 본문 값 두 개를 하나의 요소로 찾던 테스트를 수정했다. 기능 값 자체의 오류는 아니었다.
- 이 검사는 렌더링·조작·본문 존재의 검사다. 전체 내용의 교육적 충분성은 단원별 계약·설명 검토로 따로 확인한다.

원문과 JSON 링크는 로컬 absolute file URI이다. 정식 웹 패키징 전 상대 링크·원천 파일 포함, 본문 검색·메모와 기존 학습 기록 마이그레이션, 배포 확인이 남아 있다.
