# 56수업 웹 최종 확인

2026-11-19. 실제 Sites용 `web/dist/`를 로컬 HTTP로 제공해 Chromium에서 확인했습니다. 본문은 전체 Markdown 변환이며 핵심 설명을 카드로 요약하지 않습니다.

- 1500×1000·390×844에서 전체 56수업의 본문·수업 이동·페이지 가로 넘침을 확인했습니다. 표·코드는 자체 스크롤로 읽습니다. 각 수업의 원문·fixture 상대 링크가 실제 파일로 연결됩니다.
- RDF의 drive3 선택에서 두 표현의 거리 9km 대응, 추론 전후 검사, 날짜별 관계 경로와 원문, Local/Global의 보고서/원문 차이, RAPTOR의 선택 노드·문맥 예산을 조작했습니다.
- 후보 K07의 수정 이유, 위험 재분류의 404분, 집계 단위에 따른 50·40·30분, OWL 최대1/서로다름과 SHACL 결과, 30개 원천의 판·위치·본문·역할을 대조했습니다.
- 본문 전체 검색, 검색 중 비관련 단원 숨김, 영역 바로 이동, 수업 안 목차, 용어 창의 검색·본 수업 링크·본문 용어 클릭·닫기를 확인했습니다. 검색 입력의 Escape가 먼저 텍스트를 지우던 동작은 용어 창을 한 번에 닫도록 수정하고 재검사했습니다.
- 메모·책갈피·학습 표시를 다시 접속해 복원하고 JSON을 내려받았습니다. 기존 `knowledge-lab-v1` 기록이 보존되어 내보내기에 포함되고 새 완료 표시로 변환되지 않음을 확인했습니다. 이전 교재와 해시 주소는 legacy로 분리했습니다.
- 경로·트리·홈·원천 탐색 스크린샷을 실제로 열어 본문 폭·한글·범례·모바일 배치를 확인했습니다. qa/의 실행 자료는 Git에 넣지 않습니다.

17개 예제 스크립트가 산술·SQLite·RDFLib/SPARQL·선택 OWL-RL·SHACL 결과를 확인했습니다. 이 검사와 실제 학습 효과, Neo4j/모델/GraphRAG/RAPTOR 전체 엔진 실행·성능 비교는 다릅니다. 후자는 수행하지 않았습니다. 자동 검사를 사용자 이해의 보장으로 해석하지 않습니다.
