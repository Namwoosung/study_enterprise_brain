# 선택된 B안으로 연결한 학습 화면

사용자가 2026-11-19 선택한 B안의 본문/예제 병렬 읽기 구조를 작성된 실제 수업들에 적용했다. 개편 중의 로컬 통합본이며, 전체 교재·운영 사이트의 완성본은 아니다.

[학습 시작](dist/index.html). 수업 목록에서 작성된 수업을 선택한다. 그래프 비교, RAG 중간 결과, 추론/검증 결과를 해당 수업 옆에서 대조할 수 있다. 모바일에서는 관련 설명 다음으로 예제를 옮긴다. 예제가 없는 수업에서는 수업 안 목차를 제공한다.

루트에서 실행:

```powershell
.\.venv\Scripts\python.exe learning-v2/sync_manifest.py
.\.venv\Scripts\python.exe rebuild/reader/build.py
```

전체 본문과 가까운 출처 링크를 보존한다. 원문 링크는 이 로컬 검토본의 실제 파일을 가리킨다. 운영 배포 시에는 원문·예제 파일을 상대 경로로 패키징해야 한다. 기존 학습 메모·진도·사이트는 아직 변경하지 않았다. 검색은 현재 수업 제목 목록에 한정하며 본문 검색·학습 기록 마이그레이션은 추후 웹 통합 범위다.
