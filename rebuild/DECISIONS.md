# 개편 결정 기록

## 2026-11-19 · 우선 범위와 전체 확장

최신 사용자 지시에 따라 KG·Auto ontology·RAG를 먼저 웹으로 완성·배포·commit/push하고 나머지를 바로 이었다. Survey는 본편 목차의 틀이 아니라 독립 별첨으로 배치했다. 기존 B 선택을 유지하면서 필요한 곳에만 비교·자료 탐색을 더했다. 별도 새 스킬 설치 없이 본문 계약·근거 기록·독립 검토와 순차 검토를 사용했다. 보조 에이전트 사용량 한도 이후에는 주 작성자가 끝까지 집필·검토했다. 그 범위를 독립 검토로 표시하지 않는다.

## 2026-11-19 · 읽기 화면 B 선택

사용자가 실제 프로토타입 중 ‘B — 본문과 비교 예제를 나란히’를 선택했다. 전체 웹의 읽기 구조는 B를 기준으로 확장한다. 같은 디자인 선택을 다시 요청하지 않는다. 해당 수업의 학습 목적에 맞는 예제를 옆에 배치하고, 없는 예제를 장식으로 채우지 않는다. 모바일은 본문과 관련 예제를 순서대로 읽게 한다.

## 2026-11-18 · 계획 2.0

- 다음 주 실행 모델은 사용자가 선택하는 GPT-6.2.sol / high reasoning이다. 특정 모델이 긴 작업을 알아서 기억하리라는 가정 대신, 단원 계약·근거·검토·상태 파일로 작업을 나눈다.
- 사용자 운행 예제는 RDF 표현 비교의 부분 예시다. 온톨로지 설계·추출/검증·RAG 내부 과정 등은 개념별 다른 설명 방식을 사용한다.
- 새 본문 예상 규모는 30만~45만 자다. 학습 기한과 기존 짧은 구간 구조를 제약으로 사용하지 않는다. 분량은 계획 참고치이며 이해·정확성 검토를 대체하지 않는다.
- 기존 M/C/D의 표면 확장은 하지 않는다. U01~U18 + S01을 새 의미 중심 학습 흐름으로 제작한다. 실제 수업 파일 개수는 설명 길이에 맞춘다.
- 디자인은 실제 내용의 3안을 보고 선택한다. 선택 전에도 조사·Markdown 집필은 독립적으로 계속한다. 모든 작업을 운행 표본 하나의 승인에 묶지 않는다.
- 기존 전역 스킬을 삭제하거나 새 스킬을 설치하지 않았다. frontend-design·webapp-testing을 용도에 맞게 사용하고, 요약형 시각 설명 스킬을 전체 교재의 틀로 삼지 않는다.
- 현재 단계는 실행 준비다. 새 본편·새 화면·배포를 완료했다고 표시하지 않는다.
