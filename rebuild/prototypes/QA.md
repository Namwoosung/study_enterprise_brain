# 화면 프로토타입 확인 기록

2026-11-19, 주 작성자 재빌드·재검토. 이전 에이전트 작업이 호출 한도로 종료되어 최종 결과를 직접 확인했다.

- `.venv/Scripts/python.exe rebuild/prototypes/build.py`로 최신 U04 본문과 U05 발췌를 반영했다. 변환 의존성은 markdown-it-py 4.3.0이다.
- Chromium 159.0.8154.6, 1400×900 및 390×844에서 A/B/C를 확인했다. 핵심 본문 HTML이 동일한지 검사했고, 레이아웃 폭에 따른 키보드 스크롤 영역 속성 차이는 본문 차이에서 제외했다.
- 본문 12절, 앞 수업과 긴 ontology 발췌, 원문 링크, 내부 anchor, 출처 링크 표시를 확인했다. 외부 모든 URL 가용성을 자동 인증한 것은 아니다.
- drive1~3을 키보드로 선택해 RDF의 공통 주어·6개 연결, Property Graph의 3개 관계 중 강조 위치, 시각·거리·인원, 펼친 코드의 대응을 확인했다.
- 모바일에서 표·코드·도해는 해당 영역 안에서 스크롤하며 문서 전체의 가로 넘침은 없었다. 도해의 작은 글자를 해결하려고 SVG를 480px 이상으로 유지하고 가로 탐색 안내와 키보드 포커스를 제공했다.
- B의 큰 제목을 줄이고 비교 도해를 본문 도입 옆으로 올렸다. 직접 `b-desktop.png`, `c-mobile-comparison.png`를 열어 수정 후 배치를 확인했다.
- A/B 모바일 목차, C 단계 이동, 같은 절을 유지하는 안 전환, 해설 펼침, 브라우저 pageerror 부재를 검사했다.

실행: `.venv/Scripts/python.exe rebuild/prototypes/check_preview.py`.

스크린샷은 screenshots/에 있다. 기능·실제 화면의 결함 확인이며, 사용자의 디자인 선택이나 학습 효과 검증을 대체하지 않는다. 화면 선택은 요청했고 아직 답변을 받지 않았다. 운영 사이트는 교체하지 않았다.
