# 읽기 화면 세 가지

[비교 목록](index.html)에서 각 안을 엽니다. 각 안에서 U04의 같은 본문, 코드, 표, 설명 연습, 출처와 사건 비교 그림을 볼 수 있습니다. 안을 바꾸면 같은 절의 링크 위치를 이어서 엽니다.

| 화면 | 배치 | 확인할 읽기 행동 |
|---|---|---|
| [A · 긴 글 중심](a.html) | 왼쪽 목차, 가운데 수업, 문단 옆 보충 설명. 도해는 절 사이에서 넓게 표시 | 긴 설명을 읽다 앞 절로 돌아가거나 그림을 크게 보고 다시 본문을 읽기 |
| [B · 설명과 예제 나란히](b.html) | 본문 오른쪽에 사건 선택기와 도해가 머무름. 좁은 화면에서는 첫 사건의 코드와 해설 다음에 도해가 이어짐 | 스크롤하며 RDF의 트리플, Property Graph의 관계, 선택한 운전의 수치를 한 화면에서 대조하기 |
| [C · 문제부터 검증까지](c.html) | 문제, 기록, 표현, 비교, 확인 순서의 안내선. 단계 안에서 전체 본문을 계속 읽을 수 있음 | 같은 데이터를 어느 단계에서 구조화하고 검증하는지 파악하고 필요한 단계로 이동하기 |

## 화면 골격과 색

~~~text
A  [목차]  [질문과 긴 문단]  [짧은 보충 설명]
           [        넓은 비교 그림          ]
           [이어서 읽는 본문]

B  [질문과 본문]     [사건 비교]
   [코드와 해설]     [선택기와 두 그래프]
        ↓            [읽는 동안 제자리]

C  [문제 ─ 기록 ─ 표현 ─ 비교 ─ 확인]
   ● 문제
   │ [어떤 정보가 필요한가?]
   ● 기록
   │ [사건 3건의 표와 해설]
   ● 표현 → 비교 → 확인
~~~

- A의 종이색은 `#f4f5ee`, 본문색은 `#202b28`, 링크색은 `#2b5b48`입니다. 장 제목은 한글 명조를, 본문은 고딕을 사용합니다. 보충 설명은 그 설명이 필요한 문단 옆에 배치합니다.
- B의 작업 화면 바탕은 `#eff3fb`, 본문색은 `#192742`, 링크색은 `#304d8a`입니다. 같은 고딕의 굵기를 달리해 본문과 예제를 빠르게 오갈 수 있게 합니다. 도해의 강조는 읽는 구간과 선택한 사건을 각각 보입니다.
- C의 바탕은 `#f8f6fc`, 본문색은 `#2f2141`, 링크색은 `#5e387a`입니다. 표시 순서가 사건의 문제를 해결하는 순서와 일치하도록 단계 내비게이션과 본문 안내선을 정렬합니다.
- 세 안 모두 본문을 왼쪽 정렬하고, 코드는 고정폭 글꼴을 사용합니다. 기기 기본 글꼴을 우선해 외부 폰트를 내려받지 않습니다. 코드와 표는 좁은 화면에서 해당 영역만 가로로 스크롤할 수 있습니다.
- 비교 도해의 수치와 트리플은 U04 본문의 Turtle에서 가져옵니다. RDF는 선택한 사건의 여섯 발신 트리플을, Property Graph는 전체 운전 관계 세 개와 그중 선택한 관계의 속성을 표시합니다. 관계 옆 `drive1` 등의 이름은 사례의 기록 이름입니다. 원문 Cypher가 저장하는 속성은 시작 시각·거리·인원입니다.

## 다시 만들기

저장소 루트에서 `python -m pip install markdown-it-py`로 변환기를 준비한 뒤 `python rebuild/prototypes/build.py`를 실행합니다. 완성된 HTML, CSS, JavaScript는 파일을 직접 열어 읽을 수 있습니다.
